Email Setup

Configure SMTP or AWS SES for notifications, reminders, and report emails.

{% endblock %} {% block content %}
Overview

Resource Planner sends email for:

  • User creation / password reset
  • To-Do reminders and @mention notifications
  • Sprint recharge forecast and actuals
  • Project approval workflow
  • Weekly / monthly win reports

All outbound email goes through Django's email backend. You can choose SMTP (any provider) or AWS SES.

For Gmail: use an App Password (not your account password). Enable 2-FA first, then generate an app password at myaccount.google.com/apppasswords.
SESAWS SES Configuration
  1. Verify your sending domain or address in the AWS SES Console.
  2. If your account is in the SES sandbox, request production access.
  3. Create an IAM user or role with ses:SendEmail and ses:SendRawEmail permissions.
  4. Generate access keys for the IAM user.
  5. Set environment variables on the Django host:
EMAIL_BACKEND=django_ses.SESBackend
AWS_SES_REGION_NAME=us-east-1
AWS_ACCESS_KEY_ID=<access-key>
AWS_SECRET_ACCESS_KEY=<secret-key>
DEFAULT_FROM_EMAIL=noreply@example.com

Install the SES backend:

pip install django-ses
TemplatesEmail Templates

Each email type has a customisable template. Go to Settings → Email Templates and select a scenario:

  • user_created — welcome email with temporary password
  • password_reset — reset link email
  • recharge_forecast — sprint recharge forecast email
  • recharge_actuals — actuals summary email
  • project_approval — project approval notification
  • wins_weekly / wins_monthly — win report emails

Templates use a Quill rich-text editor and support dynamic variables like {{user_name}}, {{sprint_name}}. A variable panel on the right lists all available placeholders for each scenario.
