Overview

The ResourcePlanner API is a REST API that returns JSON. All endpoints live under /api/v1/. Requests must be authenticated; unauthenticated requests receive a 403 Forbidden response.

Three authentication methods are supported: Token (recommended for scripts), Session (browser / cookie), and Basic (email:password, useful for quick testing with curl).

Authentication
1 — Token Authentication (recommended)

Obtain a token by posting your email and password once. Include the token in every subsequent request header.

Obtain a token

POST /api/v1/auth/token/ Content-Type: application/json { "username": "your@email.com", "password": "your-password" } → 200 OK { "token": "9944b09199c62bcf9418ad846dd0e4bbdfc6ee4b" }

Use the token in subsequent requests

GET /api/v1/users/me/ Authorization: Token 9944b09199c62bcf9418ad846dd0e4bbdfc6ee4b

curl example

TOKEN=$(curl -s -X POST https://yourhost/api/v1/auth/token/ \ -H "Content-Type: application/json" \ -d '{"username":"your@email.com","password":"your-password"}' \ | python3 -c "import sys,json; print(json.load(sys.stdin)['token'])") curl -H "Authorization: Token $TOKEN" https://yourhost/api/v1/users/me/
2 — HTTP Basic Authentication

Pass email:password as Base64-encoded Basic credentials. Convenient for quick tests but not recommended for production scripts (credentials sent on every request).

curl -u "your@email.com:your-password" \ https://yourhost/api/v1/users/me/
3 — Python (requests library)
import requests BASE = "https://yourhost" # Obtain token r = requests.post(f"{BASE}/api/v1/auth/token/", json={"username": "your@email.com", "password": "your-password"}) r.raise_for_status() TOKEN = r.json()["token"] session = requests.Session() session.headers.update({"Authorization": f"Token {TOKEN}"}) # All subsequent calls use the session me = session.get(f"{BASE}/api/v1/users/me/").json() print(me["email"], me["first_name"])
Use Case 1 — Users API

List users, look up a specific user, and retrieve your own profile.

List all users
GET /api/v1/users/ → 200 OK { "count": 42, "next": "/api/v1/users/?page=2", "previous": null, "results": [ { "id": 1, "email": "alice@example.com", "first_name": "Alice", "last_name": "Smith", "is_active": true, "is_staff": false, "group_ids": [3], "explicit_category_ids": [], "effective_permission_ids": [...] }, ... ] }

Add ?page_size=100 to fetch more records per page (max 200). Add ?search=alice to filter by name or email.

Get a single user
GET /api/v1/users/1/ → 200 OK { "id": 1, "email": "alice@example.com", "first_name": "Alice", "last_name": "Smith", "is_active": true, "last_login": "2025-05-18T09:23:11Z", "group_ids": [3], ... }
Get your own profile
GET /api/v1/users/me/ → 200 OK { "id": 7, "email": "you@example.com", "first_name": "You", ... }
Python script — export active users to CSV
import csv, requests BASE = "https://yourhost" TOKEN = "9944b09199c62bcf9418ad846dd0e4bbdfc6ee4b" HDR = {"Authorization": f"Token {TOKEN}"} users, page = [], 1 while True: r = requests.get(f"{BASE}/api/v1/users/", params={"page": page, "page_size": 100}, headers=HDR) r.raise_for_status() data = r.json() users.extend(data["results"]) if not data["next"]: break page += 1 with open("users.csv", "w", newline="") as f: w = csv.DictWriter(f, fieldnames=["id", "email", "first_name", "last_name", "is_active"]) w.writeheader() for u in users: w.writerow({k: u.get(k, "") for k in w.fieldnames}) print(f"Exported {len(users)} users.")
Use Case 2 — Team Members API

List team members, filter by team, and check current assignments.

List team members
GET /api/v1/team-members/ → 200 OK { "count": 18, "results": [ { "id": 12, "name": "Bob Jones", "email": "bob@example.com", "role": { "id": 2, "name": "Developer" }, "employment_type": { "id": 1, "name": "Full-time" }, "is_active": true, "current_assignments": [ { "team": { "id": 5, "name": "Alpha" }, "allocation": 100 } ] }, ... ] }
Filter by delivery team
GET /api/v1/team-members/?team=5 Returns only members currently assigned to team 5.
Python script — list members with their teams
import requests BASE = "https://yourhost" TOKEN = "9944b09199c62bcf9418ad846dd0e4bbdfc6ee4b" HDR = {"Authorization": f"Token {TOKEN}"} r = requests.get(f"{BASE}/api/v1/team-members/", params={"page_size": 200}, headers=HDR) r.raise_for_status() for m in r.json()["results"]: teams = ", ".join(a["team"]["name"] for a in m.get("current_assignments", [])) print(f'{m["name"]:30s} {m["role"]["name"]:20s} teams: {teams or "—"}')
