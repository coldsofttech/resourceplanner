Quick Switch

The active engine is controlled by the DB_ENGINE environment variable. Set it before starting Django.

EngineEnv var value
SQLite (local dev)DB_ENGINE=sqlite
PostgreSQL (production)DB_ENGINE=postgresql
SQLite (Local Development)

No additional configuration required. The database file is stored at db.sqlite3 in the project root.

SQLite is the default engine when DB_ENGINE is not set or is set to sqlite. It is not suitable for production use — use PostgreSQL instead.
PostgreSQL (Production)

Set DB_ENGINE=postgresql and the following environment variables to connect to your PostgreSQL server. Install the driver with pip install psycopg2-binary (already included in requirements.txt).

Env var Default Description
DB_ENGINEsqliteMust be set to postgresql
DB_NAMEresourceplannerDatabase name
DB_USERpostgresDatabase user
DB_HOSTlocalhostHostname or IP of the PostgreSQL server
DB_PORT5432TCP port
DB_PASSWORD_SOURCEenvenv or aws
DB_PASSWORD—Password (used when DB_PASSWORD_SOURCE=env)
AWS Secrets Manager (recommended for production)

When DB_PASSWORD_SOURCE=aws, the application fetches the database password from AWS Secrets Manager at startup — the password never lives in an environment variable or config file.

Env varDefaultDescription
DB_PASSWORD_SOURCEenvSet to aws to enable
DB_SECRET_NAMEresourceplanner/db/passwordSecret name in AWS Secrets Manager
DB_SECRET_KEYpasswordJSON key inside the secret (if secret is JSON)
AWS_DEFAULT_REGIONus-east-1AWS region where the secret lives
The secret value can be a plain string (just the password) or a JSON object such as {"password": "mysecretpw"}. Use DB_SECRET_KEY to specify the JSON field name if using JSON format.
PostgreSQL + AWS Secrets Manager — Setup Steps
  1. Create a PostgreSQL database and user on your server or RDS instance.
  2. Create a secret in AWS Secrets Manager (e.g. resourceplanner/db/password) containing the password.
  3. Attach an IAM policy to your application's role granting secretsmanager:GetSecretValue on that secret ARN.
  4. Set the required env vars in your deployment environment (DB_ENGINE, DB_NAME, DB_USER, DB_HOST, DB_PASSWORD_SOURCE=aws, DB_SECRET_NAME, AWS_DEFAULT_REGION).
  5. Run python manage.py migrate against the new PostgreSQL database.
  6. Use the Test Connection button above to verify connectivity.
