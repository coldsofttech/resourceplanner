Strength Requirements
Minimum Length
Minimum number of characters required. Applied to registration and password changes.
Require Uppercase Letter
When enabled, passwords must contain at least one uppercase letter (A–Z).
Require Lowercase Letter
When enabled, passwords must contain at least one lowercase letter (a–z).
Require Digit
When enabled, passwords must contain at least one digit (0–9).
Require Special Character
When enabled, passwords must contain at least one special character (!@#$%^&*…).
History & Rotation
Password History Count
Number of previous passwords a user cannot reuse. Set to 0 to disable history checks.
Password Rotation Period (days)
Days after which users must change their password on next login. Set to 0 to disable rotation entirely.
