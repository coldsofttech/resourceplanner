Protocol & Identity Provider
SSO Protocol
oauth2 — OpenID Connect / OAuth2 (GitHub, Azure AD, Google, Okta). saml — SAML 2.0 (Azure AD SAML, ADFS, Okta SAML).
Provider Display Name
Name shown on the login page, e.g. 'GitHub', 'Azure AD'.
OAuth2 / OpenID Connect Settings
Client ID Encrypted
Application (client) ID from the identity provider.
Client Secret Encrypted
Client secret from the identity provider.
Authorization Endpoint
The IdP URL users are redirected to for authentication.
Token Endpoint
URL to exchange the authorization code for tokens.
User Info Endpoint
URL to fetch the user's profile. Leave blank if claims are in the ID token.
Scope
Space-separated OAuth2 scopes. Typical: openid email profile.
SAML 2.0 — Identity Provider
IdP Entity ID
The IdP's entity ID / Issuer found in the metadata XML.
IdP SSO URL
The IdP's Single Sign-On URL (HTTP-Redirect binding).
IdP X.509 Certificate Encrypted
Public certificate used to verify SAML assertion signatures (PEM/base64, no header/footer).
SAML 2.0 — Service Provider
SP Entity ID
This app's entity ID registered with the IdP (usually your base URL).
SP Assertion Consumer Service URL
URL the IdP posts SAML responses to. Typically https://yourhost/sso/saml/acs/.
